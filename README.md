# WebDAV 虚拟网盘管理系统（go-webdav-virtual）

本系统用于把 **115 网盘** 的文件以 **WebDAV** 的方式对外提供访问，并配套一个 **可视化管理后台**，用于完成登录、挂载目录选择、同步索引、WebDAV 账号授权、直链与 STRM 生成等日常运维操作。
<br>
Github地址：[https://github.com/fengxinzi-mulan/go-wdd](https://github.com/fengxinzi-mulan/go-wdd)

---

### 它能解决什么问题

- **把 115 网盘“变成”标准 WebDAV**：让电脑文件管理器、NAS、播放器/媒体库等，通过 WebDAV 统一访问网盘内容。
- **降低播放/刮削成本**：通过 **直链跳转** 与 **STRM 文件**，让播放器/媒体库更顺畅地获取媒体资源。
- **可控的账号与权限**：WebDAV 账号独立管理，可限制用户访问的文件夹范围与有效期。

### 部署方式

#### Docker 部署

##### 方式一：使用 docker run

```bash
docker run -d \
  --name go-wdd \
  -p 5574:5574 \
  -p 5575:5575 \
  -v /path/to/static:/app/static \
  -v /path/to/data:/app/data \
  -e TZ=Asia/Shanghai \
  --restart unless-stopped \
  wbyanzu/go-wdd:latest
```

参数说明：


> **说明**：
> - `-p 5574:5574`：管理后台/API 端口
> - `-p 5575:5575`：代理端口（用于 Emby 外网 302 代理等能力，详见 STRM 设置）
> - 程序默认会在 `/app/data` 下创建 `data.db`（SQLite）
> - STRM 默认生成到程序目录的 `/app/static/strm`

##### 方式二：使用 docker compose（推荐）

```yaml
services:
  go-wdd:
    image: wbyanzu/go-wdd:latest
    container_name: go-wdd
    restart: unless-stopped
    ports:
      - "5574:5574"
      - "5575:5575"
    volumes:
      - ./static:/app/static
      - ./data:/app/data
    environment:
      - TZ=Asia/Shanghai
```

启动服务：

```bash
docker compose up -d
```

停止服务：

```bash
docker compose down
```

查看日志：

```bash
docker compose logs -f go-wdd
```

### 快速开始（用户上手）

#### 1) 启动服务

**Docker 部署**：参考上方 [部署方式](#部署方式) 章节

**直接运行**：

- **Windows**：运行 `go-webdav-virtual.exe`
- **Linux**：参考上方 [部署方式](#部署方式) 章节
- **首次启动会创建本地数据库**：`data.db`（建议做好备份）

#### 2) 打开管理后台

- **后台地址**：`http://<服务器IP>:5574/`
- **默认管理员账号**：`admin`
- **默认管理员密码**：`123456`
- 登录时需要输入验证码（页面会展示验证码图片）。

> 端口来自 `conf/app.conf` 的 `httpport=5574`，你可以按需修改后重启。

#### 3) 登录 115 并选择挂载目录

进入后台的 **115网盘设置**：

- 先点击 **获取二维码** → 使用 115 App 扫码登录
- 登录成功后，点击 **浏览** 选择“挂载目录”
  - 挂载目录决定了 **WebDAV 可访问的顶层范围**
- 视情况调整：
  - **缓存时间（秒）**：影响直链/目录信息的缓存
  - **接口请求间隔（秒）**：过小可能更容易触发访问频率限制（默认1秒即可）
  - **同步完成生成 STRM**：开启后，同步结束会自动触发 STRM 生成任务

然后在右侧的 **同步任务状态** 区域：

- 点击 **开始同步**，先完成一次同步
  - 这一步会把目录结构/文件信息写入本地索引（`data.db`），用于 WebDAV 的目录浏览与 STRM 生成
  - 如果未同步，WebDAV 可能出现“目录为空/无法浏览”的情况

#### 4) 创建 WebDAV 账号（给播放器/客户端使用）

进入后台的 **WebDAV 用户管理**：

- 添加用户（用户名/密码）
- 可选：设置 **授权文件夹**（只允许访问指定子目录）
- 可选：设置有效期、启用/禁用

> 说明：WebDAV 的账号体系 **独立于后台管理员账号**。  
> 后台管理员用于网页登录；WebDAV 用户用于客户端 Basic Auth 认证。

#### 5) 在客户端挂载 WebDAV

- **WebDAV 信息**：选中指定用户，点击`复制`按钮，复制WebDAV登陆信息
- **认证方式**：用户名/密码（使用你在“WebDAV 用户管理”里创建的账号）
  - 首次使用请确保已完成一次“同步”，否则目录可能为空

常见用法：

- Windows：资源管理器 → “映射网络驱动器”/“添加网络位置”
- macOS：Finder → 前往服务器 → 输入上述 WebDAV 地址
- 播放器/媒体库：添加 WebDAV 源后即可浏览与播放

### STRM 的使用方式（面向播放器/媒体库）

STRM 是一种“指向真实播放地址的文本文件”。本系统会把网盘文件转换成 `.strm` 文件，内容类似：

- `http(s)://<你的域名或IP>:5574/strm/remote?pic_code=...&sign=...`

工作方式：

- 播放器读取 `.strm` → 请求 `/strm/remote`
- 系统校验签名后 **302 跳转** 到 115 的真实下载地址

你需要在后台 **STRM 设置**中配置：

- **直链服务地址（domain）**：建议填 `http://<服务器IP>:5574`（或你反代后的外网域名）
- **视频扩展名列表**：决定哪些文件会生成 `.strm`
- （可选）**下载元数据**：用于把 `.nfo/.jpg` 等文件同步到 `static/strm/`，方便媒体库刮削

生成结果位置：

- 程序目录下：`static/strm/`

### Emby 代理（5575 端口）：外网播放走 302 直链

如果你希望 **访问 Emby 时播放不走 Emby 中转**（减少服务器带宽/负载），可以使用本程序提供的 **Emby 代理端口 `5575`**：

- **你访问的 Emby 地址**：`http://<本程序IP>:5575`（或你反代后的外网域名）
- **播放时的实际行为**：客户端请求播放 → 代理在关键接口上做处理 → **返回 302 跳转到 115 的真实下载直链**，客户端直接拉取网盘直链播放

#### 1) 前置条件

- 你已经在本系统完成一次“同步”，并生成了 STRM（详见上方 STRM 章节）
- Emby 媒体库指向了 STRM 文件目录
  - 例如把本程序生成的 `static/strm/` 映射/挂载到 Emby 容器或宿主机目录后，让 Emby 扫描该目录

#### 2) 在本系统里开启/配置 Emby 代理

进入后台 **STRM 设置**，填写并保存：

- **Emby 地址（必填）**：Emby 服务的“内网可达地址”，例如 `http://192.168.1.100:8096`
  - 说明：这是给本程序用于反向代理的目标地址，所以 **本程序必须能访问到它**

保存后，程序会启动代理服务（端口固定为 `5575`）。

#### 3) 使用方式

- **内网访问 Emby**：你可以继续用原来的 Emby 地址（例如 `http://192.168.1.100:8096`）
- **外网访问 Emby（想要 302 直链播放）**：请用 **代理地址**访问 Emby：`http://<本程序IP>:5575`
  - 关键点：**只有“通过 5575 进入的播放请求”才会被代理接管并触发 302**

#### 4) 如何验证是否生效

- 用浏览器/Emby 客户端通过 `http://<本程序IP>:5575` 打开 Emby，选择一部来自 STRM 的视频播放
- 如果生效，播放请求会出现 **302 跳转**，最终拉取的是 115 的真实下载直链（不会走 Emby 的转码/中转链路）

#### 5) 常见注意事项

- **转码不会 302**：该功能面向“直通/直播”场景；如果客户端触发了转码，流量仍会走 Emby
- **Docker/网络**：如果你用 Docker 部署，确保本程序容器能访问到你填写的 Emby 地址（同网段/正确的容器网络）
- **安全建议**：`5575` 等同于“Emby 的外网入口”，建议配合反代、HTTPS、访问控制（白名单/VPN）再对公网开放

### 权限与访问控制说明（很重要）

- **WebDAV 必须认证**：访问 `/dav/` 必须提供 Basic Auth
- **挂载目录限制**：WebDAV 只能访问你选择的“挂载目录路径”范围
- **用户授权文件夹限制**：若 WebDAV 用户设置了授权文件夹，只能访问该子目录
- **有效期与启用状态**：可用于临时分享/到期自动失效

### 常见问题（FAQ）

#### Q1：能打开后台，但 WebDAV 访问 401/403？

- 401：通常是 WebDAV 用户名/密码不对，或客户端未带认证
- 403：常见原因是：
  - 该用户被禁用
  - 设置了有效期且当前不在有效期内
  - 用户授权文件夹不匹配
  - 请求路径不在挂载目录范围内

#### Q2：同步任务提示“访问太频繁/访问被阻断”？

- 建议把 **接口请求间隔（秒）** 调大一些
- 必要时重新扫码登录 115

#### Q3：为什么播放时会跳转？

- 系统对媒体文件采用 **302 跳转到真实下载链接**，这是为了让播放器直接拉取网盘文件的真实地址，通常能获得更好的播放体验。

#### Q4：我修改了配置，重启后不生效？

- 系统配置默认存储在本地数据库 `data.db` 的 `sys_data` 中（通过后台“保存配置”写入）。
- 请确认你修改的是后台配置项（115/STRM 设置），以及端口修改的是 `conf/app.conf`。

### 安全建议（强烈建议）

- **立即修改后台管理员密码**（默认 `admin/123456` 仅用于首次进入系统）
- **不要把 WebDAV 端口直接暴露到公网**，建议配合反向代理、访问控制或 VPN
- 为每个客户端创建独立的 WebDAV 用户，并设置授权目录与有效期
